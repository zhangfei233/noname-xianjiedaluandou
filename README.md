# 仙界大乱斗
基于无名杀noname制作的扩展，按自己的想法随意加入一些强力武将，并创建了一些场景和模板武将用来测试他们的强度。<br>
武将设计并没有考虑竞技强度的限制，纯粹是为了单机或者和朋友联机爽一爽。也没有考虑设计美感，缝合或借鉴了大量其他武将的技能。<br>
部分图片和代码使用了AI。<br>
beta版本属于测试版，有很多不足，例如代码可能有bug，武将语音没有制作等等。
# 使用方法
在无名杀游戏内点击扩展-制作扩展，取名“仙界大乱斗”之后保存并退出，将下载的文件放入.\resources\app\extension\仙界大乱斗 之后启动游戏即可正常游玩。
